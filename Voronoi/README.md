# Voronoi

An interactive [Voronoi diagram](https://en.wikipedia.org/wiki/Voronoi_diagram)
built with [d3-delaunay](https://github.com/d3/d3-delaunay) (ES6-imported from
esm.sh), rendered on a full-screen canvas.

Open `index.html` in a browser.

- Click empty space to add a point — the diagram recomputes live.
- Click near an existing point (within ~10px) to remove it.

Live: https://agentscript.acequia.io/agentscript/apps/Voronoi/
